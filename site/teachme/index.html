Questions

What is a skill?

A small folder of instructions and tools that teaches an AI to do one job well. It isn't an app and doesn't run by itself. The AI reads it when you ask for something it covers.

The AI isn't using it

Restart the app, then mention it by name: “use /teachme to explain how a kettle works”, or start with /teachme. To check it's installed in Claude Code, run ls ~/.claude/skills/teachme. You should see SKILL.md, README.md, LICENSE and the assets, references, scripts and templates folders.

What topics work best?

Anything with parts or steps: machines, money and economics, living processes, how institutions work, language, space. It asks who's learning (a kid, a student or an adult) and pitches the lesson to them. On debated topics it says where experts disagree.

How does it keep the facts right?

It researches the topic, writes a fact sheet, builds the lesson from it, and then a second agent checks every fact. Each lesson lists its sources and what it simplifies.

How long does a lesson take, and how many tokens?

In test runs, a lesson took about 13 minutes on average and used roughly 140,000 to 170,000 tokens, research and fact-checking included. On a Claude or ChatGPT plan this counts toward your usage; on an API it's billed per token. Changes you ask for afterwards in the same chat are much quicker.

Can I use it in a classroom?

Yes. Lessons go full screen for a display, print as a worksheet with an answer key, and work with a keyboard, screen readers, phones and reduced-motion settings. You can turn the guesses and the quiz on or off.

Is it safe to install?

It's a folder of plain-text instructions, a drawing engine, example lessons and a few helper scripts. Installing only copies them. Each lesson is a single HTML file that runs in your browser like any web page. Want to look first? Download the .zip and open SKILL.md in any text editor.

Do I need to code?

No. Ask in plain words. If you want changes, say so in the same chat: “make it for a 10-year-old”, “add a step about the thermostat”.
