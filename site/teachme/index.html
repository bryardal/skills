Questions

What is a skill?

It's a small folder of instructions and tools that teaches an AI to do one job well. It isn't an app, and it doesn't run on its own. The AI reads it when you ask for something it covers.

The AI isn't using it

Restart the app. Then name the skill in your message, like “use /teachme to explain how a kettle works”, or start your message with /teachme.

To check that it's installed in Claude Code, run ls ~/.claude/skills/teachme. You should see SKILL.md, README.md, LICENSE, and the folders assets, references, scripts and templates.

What topics work best?

Anything with parts or steps works well: machines, money, living things, how governments work, language and space. It asks who is learning (a kid, a student or an adult) and fits the lesson to them. On topics where experts disagree, it says so.

How does it keep the facts right?

It researches the topic and writes a fact sheet, then builds the lesson from that sheet. A second agent then checks every fact. Each lesson lists its sources and what it simplifies.

How long does a lesson take, and how many tokens?

In test runs, a lesson took about 13 minutes on average and used about 140,000 to 170,000 tokens. That includes the research and the fact check.

On a Claude or ChatGPT plan, this counts toward your usage. On an API, you pay per token. Changes you ask for later in the same chat are much faster.

Can I use it in a classroom?

Yes. Lessons go full screen for a class display and print as a worksheet with an answer key. They work with a keyboard, screen readers, phones and reduced-motion settings. You can turn the guesses and the quiz on or off.

Is it safe to install?

It's a folder of plain-text instructions, a drawing engine, example lessons and a few helper scripts. Installing it only copies these files. Each lesson is one HTML file that runs in your browser like any web page. To look first, download the .zip and open SKILL.md in any text editor.

Do I need to code?

No. Ask in plain words. To change a lesson, say so in the same chat, like “make it for a 10-year-old” or “add a step about the thermostat”.
